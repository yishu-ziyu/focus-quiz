## 为什么做它？

我们在阅读网页文章时，常常有一种错觉：“我看懂了”。但很多时候，我们只是把信息短暂停在工作记忆里，既没有完成主动检索，也没有把它迁移到新的情境中。

Focus Quiz 的出发点来自一个很简单的认知科学判断：如果学习只停留在复述和划重点，认知负荷会被材料本身占满；如果系统能把文本改造成可回答、可犯错、可复盘的问题，学习者才更容易暴露自己的理解断点。

所以它不做“摘要助手”，而是把选中的网页内容转成三类压力测试：

- **检索练习**：逼你从脑中调取理解，而不是回看原文。
- **反事实推演**：改变关键条件，检查你是否理解变量关系。
- **迁移应用**：换一个陌生场景，检查你是否抓住底层结构。

这不是为了让人答题上瘾，而是为了让“我好像懂了”变成“我能经得住追问”。

## 核心逻辑

Focus Quiz **不是**一个帮你总结文章的扩展，也不是一个仅仅提取名词解释的工具。它是一位极其严苛的学术导师（The Inquisitor）。它的目标是**粉碎**你脑中那些似是而非的表层认知。

当你在网页上划选一段自认为“看懂了”的文字，右键唤出 Focus Quiz 时，它会立刻向你发射三类“灵魂拷问”：

1. 🪤 **概念陷阱 (Trap)**：通过合理的错误归因和常见望文生义，测试你是否真正掌握了概念边界。
2. 🔄 **反事实推演 (Counterfactual)**：如果文中的关键条件发生逆转，结论会如何推演？（考察动态关系而非静态事实）。
3. 🌌 **场景迁移 (Transfer)**：将这段逻辑强行剥离当前语境，扔进一个完全陌生的领域，要求你重新推导。

## 核心产品特性

除了硬核的拷问逻辑，Focus Quiz 在交互层面融入了多项产品心理学设计：

- 🔥 **保留连续学习天数 (Streak)**：引入“损失厌恶”机制，侧边栏顶部实时展示连续打卡天数，一天不测，徽章熄灭重置为 0。
- 📓 **本地错题本沉淀**：你所有的“思维断裂点”都会被系统无情记录。点击侧边栏的笔记本图标 📓，随时回顾你跌落过的认知陷阱。
- 🧭 **个性化认知画像**：记录每道题的题型、正确率和作答用时，区分“概念边界 / 因果推演 / 迁移应用”三类能力，并据此调整下一轮题目难度。
- 📤 **分享“破防”时刻**：答错一题？没关系，一键复制这道极具迷惑性的题目和犀利无情的解析，发给朋友看看他们会不会中招。
- 💬 **沉浸式审问体验**：在等待大模型生成题目时，拒绝无聊的转圈动画，而是轮播 8 条极客范儿的“审问警告语录”，拉满期待值。

## 支持模型服务

完全采用 **BYOK (Bring Your Own Key)** 模式，你的密钥仅保存在浏览器本地存储中，不经过任何中转服务器。

当前版本已经从“固定 8 家 Provider”升级为 **Provider 预设 + 自定义兼容接口**：

- 原生/海外：Google Gemini、OpenAI、Anthropic Claude、Mistral
- 国内直连：DeepSeek、阿里百炼/通义千问、Moonshot/Kimi、智谱 GLM、火山方舟/豆包、MiniMax CN
- 聚合网关/高速推理：OpenRouter、302.AI、SiliconFlow、Groq、Together AI、Fireworks AI
- Token Plan / Coding Plan：MiniMax Token Plan、MiniMax Coding Plan
- 本地：Ollama
- 自定义：任意 OpenAI-Compatible 或 Anthropic-Compatible 服务

模型列表是内置快照。若服务商已经发布新模型，设置页可以直接选择“手动输入模型 ID”，无需等待项目更新。

## 安装指南

由于目前尚未上架 Chrome 商店，请通过以下开发者模式安装：

1. `Clone` 或下载本仓库代码到你的本地电脑。
2. 打开 Chrome 浏览器，在地址栏输入 `chrome://extensions/` 回车。
3. 在页面右上角开启 **“开发者模式”** 拨动开关。
4. 点击左上角的 **“加载已解压的扩展程序”**。
5. 选择你刚刚下载好、并且解压过的项目文件夹。
6. 安装成功后，请右键点击浏览器右上角的扩展图标，选择 **“选项 (Options)”**。
7. 根据指引填入你喜欢的 AI 厂商 API 密钥。

## 使用方式

1. 在任意网页中选中一段你想检验理解的文字。
2. 右键点击选区，选择 **Focus Quiz: 审问选中文本**。
3. 在 Chrome 侧边栏中等待题目生成。
4. 作答后查看解释；答题记录会进入本地认知画像，答错的题会进入本地错题本。
5. 三题完成后查看本轮诊断：表层读过 / 局部理解 / 逻辑掌握 / 可迁移使用。

点击插件图标会进入全文模式，系统会抓取当前网页正文并基于整篇文章出题；选中文字后右键则进入选区模式，适合检查单个复杂段落。

## 隐私说明

- API Key 只保存在 `chrome.storage.local`。
- 认知画像、答题记录和错题本也只保存在 `chrome.storage.local`。
- 选中的文本会发送给你在设置页选择的模型 Provider。
- 如果使用 Ollama，本地模型调用会走你配置的本地服务地址。
- 项目没有自建服务器，也不会收集用户行为数据。
- 为了支持自定义 HTTPS 模型网关，扩展声明了较宽的 HTTPS host permission；实际请求只会发往你当前选择或填写的 Provider Base URL。
